# ThinkingToDotToXML
**由想法經由AI優化，轉為dot檔案，再轉為Draw.io可編輯的檔案，協助更容易將想法轉為圖表。**
---
### 將想法轉為Dot檔案
1. 想法打的愈詳細愈好，再讓AI把想法整理為段落文字，進而將以下Prompt給AI為產出DOT檔案，有更好的文字格式。
   ''' 請將以上的內容 用以下格式輸出。系統名稱： [名稱] 主要功能： 1. [功能1] 2. [功能2] 資料流： - [來源] → [流程] → [目的地] - [涉及的資料元素] 外部實體： - [實體1] - [實體 2] 流程： - [流程 1]：[描述] - [流程 2]：[描述] 資料儲存： - [儲存 1]：[內容] - [儲存 2]：[內容] '''
2. 如此AI就會照著格式輸出系統的說明，再來就正式要求AI輸出Dot檔案了，以下是Prompt。
   ''' 請將此描述轉換為資料流程圖的 DOT 語言語法。使用正確的 DFD 表示法： - 圓圈表示流程 - 矩形表示外部實體 - 開放式矩形表示資料儲存 - 箭頭表示資料流- 在DFD圖最上方空白處建立該系統名稱的標題- 調整nodesep和ranksep參數以增加元件間距，為各種節點設定了固定的寬度和高度- 使用fixedsize確保圓形處理程序大小一致，並在標籤前加入空格以避免文字緊貼箭頭，以及調整了標題的位置和字體大小，確保文字在多行時能夠正確對齊 '''
3. 這樣就產出了 Dot 檔案，可以透過 Editor.net 這個網站來轉Dot檔案為實際的圖。
